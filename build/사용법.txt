============================================================
 Easy Saving - PDF 한 장씩 잘라 저장하기
============================================================

[ 설치 방법 - 두 가지 중 하나 ]

  (A) 파이썬 방식  ... 윈도우 11 "스마트 앱 컨트롤" 에 걸리지 않음
      build 폴더의 "설치하기_파이썬방식.bat" 더블클릭
      - 파이썬 3.9 이상 필요 (python.org, Add Python to PATH 체크)

  (B) exe 방식  ... 파이썬 없이 쓰는 사람에게 나눠 줄 때
      "설치하기.bat" 더블클릭 -> Y
      - 파란 경고창(Windows 보호)이 뜨면 [추가 정보] > [실행]
      - "스마트 앱 컨트롤" 이 켜져 있으면 차단됩니다. 그때는 (A) 방식을 쓰세요.

  * 둘 다 관리자 권한은 필요 없습니다.

[ 쓰는 방법 ]
  1. 바탕 화면 아이콘을 더블클릭하면 "저장하기" 버튼이 화면에 뜹니다.
  2. [저장하기] 클릭 -> PDF 선택 -> 끝.
  3. 바탕 화면에 "[파일이름] 저장" 폴더가 생기고,
     그 안에 "[파일이름] - 1.pdf", "- 2.pdf" ... 로 한 장씩 저장됩니다.

     예) 기안.pdf (2쪽)
         바탕 화면 / 기안 저장 / 기안 - 1.pdf
                              / 기안 - 2.pdf

[ 버튼 옆 화살표 메뉴 ]
  - 여러 파일 저장하기 : PDF 여러 개를 한 번에 (따로 / 한 폴더에 모아서)
  - 설정              : 버튼 색, 글자, 크기, 이동 조합키, 저장 위치
  - 튜토리얼 다시 보기
  - 종료

[ 버튼 위치 옮기기 ]
  Alt 키를 누른 채로 버튼을 마우스 오른쪽 버튼으로 끌면 됩니다.
  (설정에서 다른 조합으로 바꿀 수 있습니다)

[ 삭제 방법 ]
  (A) 파이썬 방식 : 바로가기를 지우고 프로그램 폴더를 삭제
  (B) exe 방식    : 설정 > 앱 > 설치된 앱 에서 "Easy Saving" 제거
                    또는 설치 폴더의 "제거하기.bat" 실행

[ 자주 묻는 것 ]
  - 저장한 PDF 는 어디에? -> 바탕 화면 (설정에서 위치 변경 가능)
  - 인터넷으로 파일이 나가나요? -> 아니요. 전부 내 컴퓨터 안에서만 처리합니다.
  - 비밀번호가 걸린 PDF -> 나눌 수 없습니다. 먼저 비밀번호를 풀어 주세요.
  - bat 창의 한글이 깨져요 -> 코드페이지 문제이며 기능에는 지장 없습니다.
